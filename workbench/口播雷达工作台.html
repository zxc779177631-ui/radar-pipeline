每日雷达（daily）

发现层 WebSearch → 抖音抓 → ≤90 天过滤。需先扫一次抖音码（扫码后 cookie 缓存）。

跑完 crawler 后，执行 python scripts/build_list.py --mode daily --max-age-days 90 生成 Markdown 清单，再在下方「导入新清单」粘贴。

定向收集（collect）

给定标签大量攒素材，不过时间，老片也收。入不入库等转完逐字稿再判。

跑完执行 python scripts/build_list.py --mode collect，再导入。

导入新清单（与现有按链接去重合并，保留已标记状态）

顶栏「导入清单.md」和这里是同一条路：按视频号去重合并，已过眼/已入库的状态不动。备份 JSON 请用「导入备份.json」（会覆盖当前数据）。
格式：**1.** [标题](https://www.douyin.com/video/ID)

导入逐字稿（匹配到候选库显示正文）

转写产物在 ~/Downloads/douyin-transcripts/。选这个文件夹，工作台会按视频 id 把逐字稿匹配到候选，候选库卡片与「过眼模式」即可显示全文。转写进行中可反复选，按 id 增量合并、不丢已标状态。

松开以导入清单 .md 或备份 .json
